# Structural visualization

> Earlier study: the current A0 geometry, parts and release holds are in [engineering-report.md](engineering-report.md). Use that report for fabrication planning.


Open [the interactive model](https://trentconley.github.io/globe/structure.html) for five views: cutaway, assembled, exploded, frame and small prototype. Drag to rotate, pinch/scroll to zoom, toggle components and select a part for its dimensions. The exploded and prototype views have an adjustable separation slider. The image button saves the current rendered model.

This model is a spatial design study. No complete physical assembly has been built. It does not contain manufacture-ready frame joints, carrier brackets, shell clips, baffle seals, fasteners, PCB layouts or a complete harness. The separately supplied small terrain-shell STLs are printable test geometry, subject to the service's process review.

The outer surface uses the same sampled geographic elevation and 25× height as the simulator. One Vancouver footprint demonstrates a 50-mile visit. The structural viewer never reads or writes the simulator's saved travel history.

## Geometry represented

| Component | Study dimensions / assumptions |
| --- | --- |
| Terrain shell | 152.5 mm sea-level radius; 151.5 mm smooth inner radius; 1 mm radial base wall plus terrain |
| Outer segmentation | 12 longitudinal gores and two polar covers; seams are provisional |
| South support opening | Nominal 13 mm bore for the 12 mm spine |
| Frame | 135 mm spherical ring centerline; 4 mm ring tube diameter; 3.4 mm meridian-rib diameter; three latitude rings, four meridian ribs and radial spokes |
| Internal carriers | 320-facet starting tessellation; six south-pole facets omitted to clear the spine, leaving 314 carrier envelopes; 144.5 mm vertex radius; 1 mm thickness |
| Full-view emitters | Ten representative dots per carrier, **not** the final 2–2.5 mm surface pitch or purchasing quantity |
| Electronics | Four illustrative 35 × 25 mm sector-board envelopes and symbolic power/data paths |
| Base | 200 mm diameter × 30 mm high; ballast and stability not established |
| First test board | 39 × 51.08 mm reference outline; 13 × 9 LEDs at 3 mm center pitch; approximate package heights and connectors |
| Prototype optical cells | 3 mm pitch, 0.36 mm wall study, top follows the shell underside with a 0.15 mm illustrated gap; intersections not unified into manufacture-ready solids |

The 12-gores layout is intentionally provisional. The finished exterior needs a seam layout chosen with the print service, hidden registration and light-blocking joints. The carrier tessellation likewise needs a complete coverage, clearance, wiring and repeated-PCB-shape study. Optical cells are modeled only in the small prototype view.

At zero layer separation the prototype shell, walls and board return to the proposed stack. The shell uses the actual Vancouver test geometry; the wall/PCB separation is a concept pending measured package heights, print tolerances, aperture alignment and light-leak tests. Gray baffle coloring makes the grid visible; the physical material should be opaque black.

## Reproduction and verification

The model is generated by preview/structure-model.js, with controls and notes in preview/structure-app.js. Run npm run build to create the standalone dist/structure.html. Serve dist locally and run node tools/check-structure.cjs with Playwright and Chromium installed. The browser check covers views, layer toggles, prototype spacing, preserved travel data, image export and phone layout.

Rendering is requested only when the view changes, rather than continuously while the page is idle. The model is a visualization mesh, not an optical, thermal or structural simulation. Physical feasibility remains subject to the staged tests in the build guide.
